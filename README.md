# Omar Yousef Portfolio

A single-page personal portfolio for Omar Yousef, built with React, Vite, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The static production output is generated in `dist/`.

## Content locations

- Profile and contact details: `src/data/profile.ts`
- Skills: `src/data/skills.ts`
- Experience: `src/data/experience.ts`
- Projects and classifications: `src/data/projects.ts`
- Services: `src/data/services.ts`
- Process: `src/data/process.ts`
- Company logos: `src/assets/images/companies/`

The existing CV is served from `public/CV-Omar-Yousef.pdf` and must not be regenerated or replaced.
